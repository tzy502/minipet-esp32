## 1. 目标与结构

- 列表式四项全展示菜单 → **滚筒选择器**：深色底 `#0a0e1a`，居中绿色 `#22c55e` 圆角框高亮选中项，上下相邻项部分裁切渐隐，右侧细滚动条指示位置。
- **无限循环（INFINITE）**：滚到末尾回绕开头，任何项都能选到；约 5 行可见窗口。
- **主交互 = 触屏**：拖拽跟手 + 惯性 + 吸附对中；点击居中项 = 确认。
- **辅助 = 单按键（1.85B）**：短按 = 确认；长按 ≥600ms = 退出/返回。
- 页面结构：根菜单（地图 / 纸娃娃 / BGM / 退出）→ 子页（同款滚筒，如"选择动作"≥8 项，带保存/返回）；每级可返回。

## 3. 触屏交互模型

### 3.1 像素 → 行换算

设行高 `H`（px），滚筒逻辑位置 `p`（单位：**行**，float，无界），按下时 `p0`、手指 `y0`：

```
拖拽中：  p(t) = p0 − (y(t) − y0) / H        （1:1 跟手，零迟滞，不做平滑）
```

符号约定：手指向下滑（Δy>0）→ 内容随手下移 → 索引减小（露出更前面的项），与系统原生滚轮/滚筒习惯一致。

行 `r` 的屏幕纵坐标（相对滚筒窗口中心）：

```
y(r) = (r − p) · H            →  选中行 = round(p)，逻辑索引 = imod(round(p), N)
```

点击命中行（点击点纵坐标 `yTap` 相对窗口中心）：

```
rTap = round(p + yTap / H)    →  命中选项 = imod(rTap, N)
```

### 3.2 三态状态机（跟手 / 惯性 / 吸附）

```
IDLE ──down──▶ DRAG ──up(位移≥10px 或 ≥300ms)──▶ COAST ──|v|<V_MIN──▶ SNAP ──|p−target|<ε──▶ IDLE
  ▲              │                                  │                     ▲
  │              └──up(位移<10px 且 <300ms)＝点击───┴─────────────────────┘
  └────────────────  down（从 COAST/SNAP 直接抓取，速度清零）◀──────────────┘
```

| 态 | 数学表达 | 参数 |
|---|---|---|
| DRAG 跟手 | `p = p0 − (y−y0)/H`，每 move 事件直接赋值 | 无平滑 → 零迟滞；同时记录样本 `(t, p)`（保留最近 8 个）用于测速 |
| COAST 惯性 | `p ← p + v·Δt`；`v ← v·e^(−Δt/τf)`，帧内离散化为每 16.7ms `v ← v·0.96` | τf≈409ms（甩一下约滑 5~8 行）；`V_MIN=0.001 行/ms`；`V_MAX=0.06 行/ms`（甩动上限） |
| SNAP 吸附 | `p ← p + (target−p)·(1−e^(−Δt/τs))`，target 进入时取 `round(p)`（或点击/步进指定行） | τs=70ms（约 210ms 收敛到 95%）；`ε=0.002 行`；**指数趋近单调无过冲 → 吸附不弹跳** |

测速：松手时取样本中距今 ≥25ms 的最早点与最后点，`v = (pLast − pFirst)/(tLast − tFirst)`；`|v| > V_MIN×1.5` 进 COAST，否则直接 SNAP。

### 3.3 点击 vs 拖拽判定

```
点击 ⇔ 总位移 < 10px 且 按下时长 < 300ms
```

- 点击命中行 == 当前居中选中行 → **确认**（进入子页 / 保存并返回 / 退出）。
- 点击命中行 ≠ 选中行 → 不确认，SNAP 到该行（"先选中再确认"两段式，防误触）。
- 两个阈值需与 LVGL 的滚动触发阈值对齐：`LV_INDEV_DEF_SCROLL_LIMIT`（默认 ~10px）——若 LVGL 先把触摸判成滚动，CLICKED 事件不会发；保持 10px 一致即可复用默认值。

### 3.4 滚轮 / 键盘映射

| 输入 | 行为 |
|---|---|
| 滚轮 | 累计 `deltaY`，每满 40 走 ±1 行（SNAP 中再次触发 → target 累加，连滚不顿挫）；累计值每帧 ×0.9 清退 |
| ↑ / ↓ | `step(±1)`：SNAP 态 `target += ±1`，否则 `target = round(p) ± 1` 进 SNAP |
| Enter | 确认当前居中项（等同短按） |
| Esc | 返回上级；根菜单时提示"真机长按退出" |

## 4. 无限回绕算法

逻辑行号 `r ∈ ℤ` 无界，**任何时刻不夹取、不回卷 `p` 本身**；只在与"选项"交界处取模：

```
显示索引(r) = ((r mod N) + N) mod N          // 负数安全取模
```

窗口渲染（每帧）：对每个槽位偏移 `s ∈ [−span … +span]`（span=可见半窗+2 缓冲）：

```c
/* C 伪代码（注意 C 的 % 跟随被除数符号，必须修正负数） */
static inline int32_t imod(int32_t v, int32_t n) {
    int32_t r = v % n;
    return (r < 0) ? r + n : r;
}
int32_t base = (int32_t)lroundf(pos);
for (int32_t s = -span; s <= span; s++) {
    int32_t row  = base + s;
    float   y    = ((float)row - pos) * row_h;   /* 槽位纵坐标 */
    int32_t item = imod(row, opt_cnt);           /* 该槽位显示的选项 */
    /* item 变化才重设文本；按 |row-pos| 设透明度/缩放 */
}
```

要点：

1. **首尾相接是"自然涌现"的**：`p` 连续、槽位按连续 `y` 摆放、文本按 mod 映射 → 跨越 `N→0` 边界时文字原地切换，无跳变、无动画接缝。
2. **负数取模**：JS `%` 与 C `%` 都跟随被除数符号（`-1 % 10 == -1`），必须用上式修正（原型 `imod()` 已实现并冒烟验证：`imod(-1,10)=9`）。
3. **N < 可见行数时**（根菜单 4 项 < 5 行）：同一窗口内同一选项会出现两次（如 `… 2 3 0 1 2 …`），这是循环滚筒的标准表现；LVGL INFINITE 模式同样如此。若观感不可接受，见 §9 风险 R1。
4. 滚动条位置比例 = `imod(p, N) / N`（float 版同式），回绕时拇指从底回到顶，是预期行为。

## 5. LVGL v9 映射结论

### 5.0 结论（一句话）

**原生 `lv_roller` + `LV_ROLLER_MODE_INFINITE` 可以直接覆盖本次需求的全部核心行为——无限回绕、触摸拖拽跟手、松手惯性、吸附对中、滚轮/键微调都开箱即用；需要自己加的只有四件外围件（圆角高亮框、上下渐隐、点击居中项=确认的二次判定、自绘位置指示条），以及一个待验证项（N 小于可见行数时的观感）。** 若实测手感（惯性衰减）不达标，再退到自研 widget 方案 B（§5.3），其数学已在原型中验证。

### 5.1 需求点 → 原生支持对照表

| 需求点 | 原生 lv_roller v9 | 用法 / 缺口 |
|---|---|---|
| 无限回绕 | **支持** | `lv_roller_set_options(r, "…\n…", LV_ROLLER_MODE_INFINITE)`。实现机制：内部把选项串复制一份（内容 ≈ 2N 行），滚过边界时无动画平移 N×行高归位，视觉无缝 |
| 触摸拖拽跟手 | **支持** | roller 是可滚动对象，触摸 indev（`esp_lvgl_adapter` 已把触摸注册为 `lv_indev`）直接驱动其滚动 |
| 松手惯性 | **支持** | LVGL scroll momentum 默认开启（`LV_OBJ_FLAG_SCROLL_MOMENTUM`） |
| 吸附对中 | **支持** | roller 内部基于 scroll snap 居中 + `LV_EVENT_SCROLL_ENDED` 对齐；松手后自动停到行中心 |
| 滚轮 / 键微调 | **支持** | roller 加入 `lv_group` 后响应 `LV_KEY_UP/DOWN/LEFT/RIGHT`（上/左=前一项，下/右=后一项）；`LV_KEY_ENTER` 不由 roller 消费 → 确认动作自行接线 |
| 选中变化事件 | **支持** | `LV_EVENT_VALUE_CHANGED` + `lv_roller_get_selected()` |
| 窗口行数 | **支持** | `lv_roller_set_visible_row_count(r, 5)`（480）/ `(r, 3)`（360） |
| **圆角绿色高亮框** | 部分 | `LV_PART_SELECTED` 可设 bg/border/radius，但选中底色**横贯整个 roller 宽度且不可内缩**，只能得到"全宽圆角色带"；要"内缩圆角框"（参考稿样式）→ **加一个居中覆盖的 `lv_obj` 框**（`lv_obj_clear_flag(frame, LV_OBJ_FLAG_CLICKABLE)` 让触摸穿透），推荐此法 |
| **上下渐隐** | 不支持 | roller 的所有行是**同一个 label**，无法按行设透明度 → 用**上下两条渐变遮罩对象**盖住窗口边缘（v9 渐变 stop 支持不透明度，或预烘焙两条 ARGB 渐变图），遮罩不参与滚动、不可点击 |
| **点击居中项=确认** | 不支持 | 默认点击任意行=滚动选中该行（选中变化才发 VALUE_CHANGED；点已选中行无事件）→ 自加 `LV_EVENT_CLICKED` 回调，用点击 y 反算命中行（§3.1 公式），命中行==`lv_roller_get_selected()` 才触发确认 |
| **右侧位置指示条** | 不建议原生 | `LV_PART_SCROLLBAR` 可样式化（宽 3px/圆角/绿色），但 INFINITE 回绕瞬间滚动条**跳变** → 关掉原生滚动条（`lv_obj_set_scrollbar_mode(r, LV_SCROLLBAR_MODE_OFF)`），自绘一个小 `lv_obj` 按 `imod(p,N)/N` 移动（需在 `LV_EVENT_SCROLL_CHANGED` 里读 `lv_obj_get_scroll_y(r)` 换算 p） |
| 惯性衰减手感参数 | **不可配** | v9 未按对象暴露滚动阻尼；若默认衰减太飘/太肉，只能改源码 → 触发方案 B 决策（§5.3） |
| 中文文本 | 支持 | 字体自行烘焙（见 §9 风险 R2）；`lv_obj_set_style_text_line_space()` 可微调行距（行高=字体行高+行间距，**行高 H 随之确定**，像素换算按实际渲染行高） |

### 5.2 推荐落地方案 A（原生 roller + 4 件外围件）

```c
lv_obj_t *r = lv_roller_create(parent);
lv_roller_set_options(r, "地图\n纸娃娃\nBGM\n退出", LV_ROLLER_MODE_INFINITE);
lv_roller_set_visible_row_count(r, 5);            /* 480 屏；圆屏传 3 */
lv_roller_set_selected(r, 0, LV_ANIM_OFF);

/* ① 全宽色带改内缩圆角框： roller 样式只留文字 */
lv_obj_set_style_bg_opa(r, LV_OPA_TRANSP, LV_PART_SELECTED);   /* 关掉默认选中底色 */
/* ② 覆盖层：绿色圆角框 / 上下渐变遮罩 / 自绘滚动条，均 clear CLICKABLE */
/* ③ 事件： */
/*   LV_EVENT_VALUE_CHANGED → 记录新选中（业务态同步）         */
/*   LV_EVENT_CLICKED       → 反算命中行，==当前选中 → 确认    */
/*   LV_EVENT_SCROLL_CHANGED→ 自绘滚动条按 imod(p,N)/N 移动     */
```

事件回调跑在渲染任务的 LVGL 上下文里（`esp_lvgl_adapter` 的 lv_timer 驱动），与现有 `menu_tick_cb` 同任务，可直接沿用现有"落旗标 + tick 消费"的跨模块约定（`req_act / req_ok / req_exit` 模式不变）。

### 5.3 备选方案 B（自研滚筒 widget）与决策树

```
方案 A 跑分/手感验收
  ├─ INFINITE 回绕 OK？ ──否（N<可见行出现难看空档）──▶ 方案 B
  ├─ 惯性手感可接受？ ──否（衰减不可调）──────────────▶ 方案 B
  └─ 都 OK ────────────────────────────────────────▶ 方案 A 定稿
```

方案 B 要点：关 roller 的可滚属性（或直接用 `lv_label` + 自绘），在 `LV_EVENT_PRESSING / PRESS_LOST / RELEASED` 里自实现 §3.2 三态（把原型 JS 数学直译成 C，`p/v` 用 float，每帧渲染槽位）；工作量约 +2~3 天，但手感参数完全可控（原型参数表 §8 即 C 默认值）。

### 5.4 与现有渲染/输入架构的兼容性

1. **DIRECT 模式 / menu_buf 整帧 memcpy**：兼容。滚筒动画期间由滚动区域失效驱动重绘（进 `menu_buf` 后每帧整拷上屏），现有 100ms 全屏 invalidate 的"清影兜底"保留不动，不构成帧率上限。
2. **动画帧率**：LVGL 默认刷新周期 33ms → 滚筒约 30fps；拖拽跟手依赖 indev 采样率（触摸中断→adapter 上报），无需改渲染任务节拍；`menu_tick_cb` 的 100ms 业务节拍（下载轮询/网络态重建）与滚筒动画解耦，保留。
3. **触摸路径**：现有菜单是"行按钮点击 → req_act 落旗标"；方案 A 改为 roller 事件回调 → 同样的旗标机制，`input_dispatch.c` 不动。
4. **遮罩/框/滚动条覆盖层**：三个小对象 + 现有重建逻辑（`menu_rebuild()` 里创建一次，换页只改文本）。
5. **单按键**：`key_gpio18.c` 目前只有"按下沿"回调 → 需**扩展长按判定**（在按键任务里计时：按住 ≥600ms 且未松开 → LONG 事件；先长按触发则抑制随后的短按）。这是驱动层的既有缺口，与滚筒无关但为 1.85B 必需。

## 7. 事件表（输入 → 状态迁移）

| 输入 | 判定 | 状态迁移 / 动作 |
|---|---|---|
| 触摸 down | — | 记录 `(t0, y0, p0)`；COAST/SNAP → **DRAG**（抓取，v=0）；IDLE → DRAG |
| 触摸 move | DRAG 中 | `p = p0 − Δy/H`（跟手）；滚动样本入队；区域失效重绘 |
| 触摸 up | 位移<10px 且 <300ms | **点击**：命中行==选中行 → 确认（见下"确认"行）；否则 → SNAP(命中行) |
| 触摸 up | 位移≥10px 或 ≥300ms | 测速：`|v|>V_MIN×1.5` → **COAST**；否则 → SNAP(round(p)) |
| 触摸 cancel | — | 等价 up（禁止点击），SNAP(round(p)) |
| 滚轮 | 累计 deltaY≥40 | SNAP：SNAP 态 target±1（连滚累加）；非 SNAP 态 target=round(p)±1 |
| 键 ↑/↓ | — | 同滚轮 ±1 |
| 短按（<600ms）/ Enter | — | **确认**：根页 → 地图/纸娃娃/BGM 进对应子页，"退出"→ 退出菜单；子页 → 保存并返回根页 |
| 长按（≥600ms）/ Esc | — | 子页 → 返回根页（不保存）；根页 → 退出菜单（回桌宠主界面） |
| 页面迁移 | — | 进子页：pos=该页记忆的选中行，SNAP 直达；返回：pos=根页记忆选中行 |

注：1.85B **无触摸时的降级交互为可选**（用户已明确）：单键只有"确认/退出"两义，移动选择必须另立约定（候选：长按进入"滚动模式"后每次短按走一行、再长按退出；或旋转编码器外设）。原型"仅按键模式"用 ↑↓ 模拟该降级方案的验证通路，真机方案见 §9 开放问题 Q4。

## 8. 手感参数表（JS 原型 ↔ C 等效）

| 参数 | 原型常量 | 值 | C 等效/备注 |
|---|---|---|---|
| 惯性衰减 | `FRICTION_PER_FRAME` | 每 16.7ms ×0.96 | τf = 16.7/ln(1/0.96) ≈ 409ms；C 中按 `v *= expf(-dt/409.0f)` |

## 10. 验收清单（对照原型逐条可勾选）

- [ ] 拖拽：按住滚筒 1:1 跟手（无迟滞、无回弹），双屏同步
- [ ] 惯性：快甩滑 5~8 行，指数衰减自然；慢拖松手就近吸附
- [ ] 吸附：约 200ms 对中，无过冲弹跳
- [ ] 点击：点居中项=确认进子页；点两侧项=滚到该行不确认；位移/时长阈值生效
- [ ] 无限循环：任一页滚过末项无缝回绕首项（正反两方向），根菜单 4 项同样循环
- [ ] 滚动条：随选中比例移动，回绕时回到顶端
- [ ] 滚轮 / ↑↓ 微调、Enter 确认、Esc 返回上级
- [ ] 子页（选择动作 ≥8 项）：保存=记录并回根页；返回=不保存；每页记忆上次选择
- [ ] 480 屏 5 行 / 360 圆屏 3 行，字号、标题、按钮带、滚动条均在圆弧安全区内
- [ ] 仅按键模式：拖拽/滚轮被禁用，↑↓+Enter+Esc 可走完全流程（根→子页→保存→退出）
